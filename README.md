# ربات انتشار خودکار کانال تلگرام

این برنامه با API سازگار Groq یک پست فارسی تولید می‌کند و در کانال تلگرام منتشر می‌کند.

## انتشار خودکار ابری با GitHub Actions

پس از افزودن فایل‌ها به مخزن، از مسیر Settings → Secrets and variables → Actions سه Secret بساز:

- `TELEGRAM_TOKEN`: توکن ربات تلگرام
- `CHANNEL_ID`: مقدار `@imanzangi1258`
- `GROQ_API_KEY`: کلید API سرویس Groq

مقادیر محرمانه را فقط در بخش Secrets وارد کن؛ هرگز آن‌ها را در فایل‌های مخزن یا چت قرار نده.

فایل workflow در مسیر `.github/workflows/post.yml` هر سه ساعت یک‌بار اجرا می‌شود. زمان‌بندی GitHub بر اساس UTC است؛ ممکن است ساعت محلی آمستردام با تغییر ساعت تابستانی جابه‌جا شود. اجرای زمان‌بندی‌شده ممکن است چند دقیقه تأخیر داشته باشد.

برای اجرای آزمایشی دستی: زبانه Actions → Telegram auto post → Run workflow.

## اجرای محلی

در فایل `.env` مقادیر زیر را قرار بده:
- `TELEGRAM_TOKEN`
- `CHANNEL_ID`
- `GROQ_API_KEY`
- `GROQ_BASE_URL=https://api.groq.com/openai/v1`
- `MODEL_NAME=openai/gpt-oss-20b`
- `TIMEZONE=Europe/Amsterdam`

ربات باید در کانال مدیر و دارای مجوز ارسال پیام باشد. فایل `.env` را در GitHub قرار نده.

در ویندوز ابتدا `setup.bat` و سپس `start.bat` را اجرا کن. اجرای محلی فقط تا وقتی لپ‌تاپ روشن و برنامه فعال است ادامه دارد.

## هزینه و سهمیه

GitHub Actions و API هوش مصنوعی ممکن است مشمول محدودیت یا هزینه بر اساس حساب و میزان استفاده باشند. پیش از فعال‌کردن هر طرح پولی، شرایط حساب را بررسی کن. این پروژه هیچ سرویس پولی را خودکار فعال نمی‌کند.
